# 更新与部署

电脑 PowerShell 推送（仅加入此次修改，不加入 public 下旧的大型压缩包）：

```powershell
cd D:\float\ai-virtual-phone
git add components/mixology lib/mixology components/mobile-viewport-controller.tsx scripts/check-mixology-entries.cjs tools/tavern-workshop
git commit -m "Support editable preset entries and regex rules; fix mixology tabs and frame sizing"
git push origin main
```

手机 Termux：先在原服务窗口按 Ctrl+C 停止，再进入手机原有的项目目录。以下假定为 ~/ai-virtual-phone，不同则替换 cd 路径。

```sh
cd ~/ai-virtual-phone
git pull --ff-only origin main
npm install
npm run build
npm start
```

逐条执行，上一步报错先解决再继续。npm start 默认监听 localhost:3001；手机浏览器打开 http://127.0.0.1:3001。原本设置过端口或其他环境变量的，继续沿用原启动方式。保留原 .env.local，不需要重新克隆，不要清除浏览器站点数据。

如果此前 Termux 是在 proot Linux 环境中运行，也在原来的环境、原来的项目目录执行。若使用电脑预编译的 .next 压缩包部署，git pull 只更新源码，仍需要用重新编译的包替换旧 .next，旧 next-prod.tar.gz / next-build.zip 不能用于本次更新。仓库里这两个旧包没有加入此次推送命令。

电脑本地运行：

```powershell
cd D:\float\ai-virtual-phone
npm run build
npm start
```

打开 http://localhost:3001。

工作台 HTML 已同步到 tools/tavern-workshop/index.html；工坊 ZIP 是 tools/tavern-workshop/酒馆工坊_小手机应用包.zip，版本 1.2.0。更新小手机后，在应用市场通过本地文件导入 ZIP 更新酒馆工坊。此步骤独立于源码更新。

预设与正则编辑：独家特调 → 酒柜 → 分类 → 点击材料 → 编辑。预设展开条目修改名称、正文、启用与顺序；滤网支持逐条命名、开关和排序。旧合并材料不会自动恢复原条目，重新转换/导入新版文件，再在配方中选择新版基底、苦精和滤网。导入产生新的材料，不会替换原材料。

火狐恢复补丁需要更新后的页面才能生效，刷新后再测试切后台返回；目前验证包括模拟延迟视口恢复，未在你的手机 Firefox 上验证。

## 整杯配方包只读修复

上一版的整杯本地配方包导入误标记为他人作品，导致只有删除和关闭、没有编辑。本版已修复：更新 App 后重新导入原本的本地配方包，即可解除同 ID 材料的误标记。详情页显示可展开的条目列表，并有“编辑预设条目”按钮。资源集市下载的他人作品仍遵循原有编辑限制。
