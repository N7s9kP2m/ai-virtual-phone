# 酒馆工坊

`index.html` 是可直接在浏览器打开的转换工作台；`酒馆工坊_小手机应用包.zip` 是应用市场可导入的 1.2.0 应用包。

独家特调预设转换保留文本条目的名称、正文、启用状态、顺序和原始条目。关闭条目不会进入生成提示词。连续属于同一槽位的条目放在同一材料的 entries 数组内，酒柜编辑器支持逐条编辑、启用、上下移动、添加和删除。content 为兼容旧版保留启用条目的快照，新版生成以 entries 为准。

正则保留可转换规则的名称、启用状态、顺序和原始来源。无法等价转换的规则显示在转换说明中。导入前可以查看转换预览。

酒馆动态宏目前静态展开；开关涉及 setvar/getvar 的条目不会重算其他条目的变量。需要改变这类逻辑时，在酒馆调整后重新转换。历史深度、独立消息角色、采样参数和外部脚本等按工作台的转换提示处理。

旧版合并预设仍兼容；要恢复原条目，重新转换原酒馆文件并导入。旧材料“改为条目编辑”保留原内容为一条，不猜测原条目边界。文件导入产生新材料，请在配方里重新选择新材料。

应用 ZIP 已有同一应用 ID，请通过应用市场本地导入更新；如果系统不允许覆盖，可卸载旧工坊后重新导入（先导出工坊自己的数据）。
